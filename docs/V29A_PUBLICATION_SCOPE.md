# V29A publication and reproducibility boundary

Danny authorized freezing, committing and pushing V29A as evidence and lessons
learned after reviewing the verified NO_GO result. This release publishes the
original research contract, review, exact approved package, implementation,
tests, historical approval receipts, selected raw evidence, complete official
paired metrics, failed gates and an additive lessons-learned document.
It does not promote V29A, authorize another run or change the selected submissions.

`v29a_release_freeze_20260928.json` inventories the exact published artifacts and
their raw SHA-256 digests. Git attributes preserve pinned bytes, including
historical CRLF line endings. Historical PROPOSED and NOT_APPROVED documents are
retained as written; the separate approved research receipt records the authority
for the single completed execution. It is not standing permission to rerun.

Published evidence includes all 19 candidate artifacts, the source bundle and
manifest, the approved dispatch notebook, completion and verification records,
the 199 baseline and 199 TTA inference records, seven timing-control records,
two repeat records, visible-sample records, and the full official result with
all 199 paired metric rows and score deltas. The original failed test report and
operational failure evidence remain inspectable. No scientific source file,
frozen contract, threshold or original metric result was rewritten for release.

A fresh clone can inspect the complete decision and approval chain, verify the
published raw-byte identities, inspect the embedded source bundle, and run the
focused unit tests after installing dependencies and pytest. The release does
not bundle the raw microscopy images, GEFF labels, checkpoint binaries, full
offline dependency collection, 398 coordinate arrays, visible CSV or historical
cohort ZIP archive. The inventories retain identities for excluded local files;
an absent artifact is not evidence that its hash matches.

Full graph reconstruction, execution of the builder, and rerunning the final
evidence auditor require their named local inputs. GPU replay additionally
requires the pinned support/checkpoint datasets, competition access, recorded
software environment and a new explicit execution approval. A Git clone alone
does not provide an exact replay of the scientific experiment.

Transient status polls, duplicate live-event streams and most account/runtime
logs remain local. Selected API observations record only the relevant completed
job and final-selection state. No credentials or signed download URLs belong
in this publication. The unrelated modified V25 notebook and other local work
are excluded, and all 76 frozen V28 release artifacts remain byte-identical.

The official result is a local development comparison on 199 already-opened
samples. The 0.735928 TTA score is not a Kaggle submission score. V28's observed
public score remains 0.728; V29A's promotion decision remains NO_GO.
